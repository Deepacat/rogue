The files in this folder are used to overwrite minecrafts default unifont (The fallback unicode font)<br>

It is replaced with a much smoother font to make reading it easier, since plenty of book mods<br>
decide to use the unifont rendering by default, and I quite dislike the base unifont.

The font can be replaced with any `.ttf` or `.otf` file then putting its name in `uniform.json`.

Do not use capitals as it follows regular minecraft resource location rules.

You can set `force unicode font` in the minecraft language settings to test your font on all text.

I would recommend installing a mod with some patchouli book like `botania` to test the `"shift"` values until no text overlaps.

Ensure any custom font you add is under an open source license so you may legally use it.<br>
You may browse a list of FOSS (Free and open source) fonts here: https://fonts.google.com/
